# Historical TESS zodiacal sky-floor golden

Run `python gold_tess.py` from the package root. The replay starts from 59 measured floor rates and their selected epochs in `cutouts.csv`. Each row identifies one 21 × 21 TESScut product by position, sector, camera, CCD, original filename, MAST request URL and SHA-256 of the uncompressed FITS file as received. MAST may regenerate a file on request. The digests identify the historical input bytes.

The measurement starts from the sigma-clipped median over pixels in each cadence (3 sigma, five iterations). It permits the predicted scattered-light flag 2048, excludes other quality flags and splits segments at gaps greater than one day. Each retained segment spans at least two days and has at least 20 cadences. The original pipeline selected the minimum of the 0.5-day running median of the measured-to-model ratio, then the lowest segment floor in each cutout. The rate column holds that selected measurement in electrons per native pixel per second. The epoch selection used the original model. The full set of 59 time series can be retrieved from the manifest; the offline package includes a pixel replay for one field.

At each epoch the code evaluates the packaged STScI ETC table with the Leinert colour law and the historical T-band-consistent Vega factor of 1.021408688828167. The frozen minor-light midpoint represents the dust-map DGL and unresolved Gaia-light bracket in the same convention. The geometry checks use an Astropy frame transformation, a separate Meeus solar longitude and the nominal acquisition latitude. An independent SciPy interpolation in linear radiance checks the ETC implementation at the floor geometries. The numerical regression tolerance of one part in a billion applies to the recalculated zodiacal rates with the pinned dependencies.

Five ecliptic-plane cutouts have median measured floor divided by modeled floor of 0.918298. The historical two-sigma envelope begins at 0.919480. For the 48 anti-solar cutouts the code fits measured versus modeled electron rates per square arcsecond with an unweighted slope and intercept. RMS of the residual divided by the measured value is 0.048108, above the historical budget of 0.036640. Both observational discrepancies remain open under the declared calibration. Five Sun-side high-latitude cases and one excluded corner-glow case take part in the geometry and model-rate checks only.

For the Sector 3 field the historical operator also runs from pixels offline with `python tess_floor.py`. The 1,288 TIME and QUALITY entries and the central 21 × 21 FLUX values of the bundled 25 × 25 FITS agree element by element with a new MAST response to the original 21 × 21 request (including the positions of missing values). The WCS headers differ slightly. Using either product gives the original epoch 1402.78345844 BTJD and floor 78.31061071 e⁻/pixel/s. MAST's regenerated FITS file digest differs from the original. To remeasure another field, use its CSV request URL, extract the FITS with the recorded filename, then run `python tess_floor.py path/to/file.fits`. The output gives its byte identity comparison and its measured difference. The default golden checks the Sector 3 result.

The package's separate `tess.py` example fits stars and sky over the later 25 × 25 field. It yields 78.947314 e⁻/pixel/s. The 57 selected total-sky units have their own measurement and model.
