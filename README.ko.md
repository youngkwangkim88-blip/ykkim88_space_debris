# A1 파편 광학·하늘 배경 재현 예제

Python 3.10 환경에서 아래 두 명령을 실행한다. 의존성을 설치한 뒤에는 기본 예제에 필요한 관측 영상과 모형 입력이 모두 이 폴더에 있다. [영문 실행 안내](README.md) · [원자료와 이용 조건](SOURCES.md)

```sh
python -m pip install -r requirements.txt
python reproduce.py
```

- **파편** — `python fragment.py`는 10 cm 회색판의 초기 자세·회전축 100쌍을 적산한다. 4초 E12에서 조명을 같은 8월 조건으로 유지하면 약한 하늘과 강한 하늘의 SNR 10 거리 중앙값은 각각 306.0 km와 275.5 km다. `python fragment.py --shape cuboid --material solar_cell --band E5 --exposure 0.5`로 형상·재질·대역·노출을 바꿀 수 있다.
- **하늘** — `python sky.py`는 황도광, 등방 잔여광, 확산 은하광, 미분해 별빛과 달 미광을 성분별로 계산한다. 7월 관측 기하에서 달을 28.5°에 놓은 사례는 별도의 가상 조건이다.
- **단노출 합성** — `python coadd.py`는 같은 네 초 동안 수집한 광자를 단일 4초 노출 또는 2·0.5·0.1초 판독으로 나누어, 한 장으로 합쳤을 때와 시간순 원본을 보존했을 때의 가중 SNR을 대조한다.
- **TESS 실측** — `python tess.py`는 동봉한 25×25화소 FITS에서 731개 시점으로 배경 78.947314 e⁻/화소/s를 얻는다. 총배경 오차 9.80885%는 별도 관측창 250개의 측광표를 방문·표본 순으로 집계한 값이다.
- **통계 검산** — `python factors.py`는 저장된 SNR 격자에서 표 5.1을 계산한다. `python reproduce.py`는 위 예제와 광자·판독잡음을 새로 뽑는 512회 분산 검산을 함께 실행한다.

## 골든 테스트 재현

`python goldens.py`로 모두 실행하거나, 명령 뒤에 아래 그룹 중 하나를 붙여 개별적으로 실행할 수 있다.

| 그룹 | 비교 대상과 결과 |
| --- | --- |
| `tess` | 과거 21×21 컷아웃 59개의 관측 바닥값과 해당 시각에서 계산한 황도광을 대조한다. 황도면 5개의 관측/모형 중앙값은 0.91830, 반태양 방향 48개의 선형 적합 후 상대 RMS는 4.811%였다. 각각 당시 허용 범위를 벗어났다. 각 컷아웃의 MAST 요청도 제공한다. [관측값과 절차](data/goldens/tess/README.md) |
| `tess_paper` | v27의 250개 관측창에서 실제 시각·시선·TESS 대역 계수로 황도광, 확산 은하광과 등방 잔여광을 다시 계산한다. 보관된 관측값·미분해 별빛을 사용해 98회 방문과 57개 표본을 집계하고 원고의 총배경 상대오차를 복원한다. [입력과 검산](data/goldens/tess_paper/README.md) |
| `blender` | Blender 선형 영상을 화소 단위로 적분한다. 세 형상·세 자세·두 반사법칙의 18조건에서 최대 상대차는 0.107%다. 이 중 판형 6조건은 공개 파편 광도 함수를 직접 검사한다. 별도 회전 노출은 36개 시점의 광속을 적산한다. [영상 자료와 재렌더링 방법](data/goldens/blender/README.md) |
| `motion` | 초기 궤도 상태 16,000개를 노출 전체에 걸쳐 전파하고, 광자 중심의 예측 위치 공분산을 비선형 투영 표본과 대조한다. 궤적 위에서 광자가 퍼지는 폭도 별도로 출력한다. |
| `calibration` | 화소마다 감도와 암전류가 다른 검출기에서 4초 고정 광원을 관측한 원고의 20,000회 실험이다. 보정만 고려한 분산비는 1.00164, 과학 영상의 잡음까지 포함하면 0.99052다. |
| `coadd` | 새로 추가한 30,000회 실험에서 같은 다크·플랫으로 보정한 세 노출의 광량 공분산을 확인한다. 광적이 한 화소 이동해 겹치는 두 측정의 보정 공분산은 예측 1.910, 실측 1.908 e⁻²다. |
| `photometry` | 원래의 운용 측광 함수와 보충자료의 몬테카를로를 실행한다. 기준 배경을 아는 사례에서 측정/예측 분산비는 0.9952–1.0047이다. 독립 영상 8장의 중앙값으로 배경을 추정하면 같은 예측에 대한 분산비는 1.1605다. 두 카메라의 4초 이동 광적에서는 광량 표준편차를 대조한다. [식 (2) 사용 예제](data/goldens/photometry/README.md) |

논문의 SNR 10 거리는 식 (1)의 기대 전자수로 계산한다. 운용 SNR은 관측 영상에서 추정 배경을 뺀 잔차와 후보 궤적의 템플릿으로 식 (2)를 적용한 값이다. 후보 탐색 뒤의 검출률을 구하려면 별도의 탐색·오경보 평가가 필요하다.
